# Fable creative direction and production

DFM requested Claude Fable 5.1 for the X copy and short promotional video on 2026-09-11.

The native Claude CLI was invoked with the explicit model `claude-fable-5-1`, medium effort, no session persistence, plan permissions, and no tools for the copy/storyboard call. The successful result reported `claude-fable-5-1` in model usage; it also listed an auxiliary Haiku model. No fallback model was requested. An earlier larger request through the router ended with SIGTERM before delivering a result; its output was not used.

`fable-storyboard.json` preserves the original creative response, which used the earlier private-repository brief. The final GitHub API check reported `visibility: public`. Fable was called again with the same explicit model and no tools to revise the CTA and both posts for a public repository. `fable-public-revision.json` preserves that response; the two post files preserve its copy verbatim. No repository visibility was changed during this task. Raw CLI envelopes, account metadata, and local run logs are not included in this directory.

Codex implemented the storyboard with a deterministic Pillow/FFmpeg renderer. Adaptations for this cut:

- Installed Arial/Arial Bold and Menlo substitute for the proposed Inter and JetBrains Mono fonts; no font binaries are distributed.
- The opening reads “Quota wall. Mid-session.” with an illustrated terminal.
- Motion uses route lines, a moving request indicator, small entrance movements, and staggered feature labels. The suggested 3D tilt and screen shake were omitted.
- The retry-scope sentence is held for the full failover scene, giving viewers longer to read it.
- The dashboard shows the complete quota table cropped from the sample renderer export. Large labels explain the features; small table text is supporting interface detail.
- The final public-repo CTA remains on screen for the entire last three seconds. It uses Fable's revised title, feature line, URL, and verification note, with an added “GET STARTED ON GITHUB” label.

The video is silent. All diagrams and terminal mockups are original drawing primitives. The dashboard image is generated by this repository. No desktop captures, account credentials, third-party music, or provider logos are used.

The rendered stills and post copy were submitted to the same explicit Fable 5.1 model for a separate read-only review. Review results are recorded in `fable-review.md`. Motion and encoding verification are performed locally; a still-image review does not establish video playback quality or real quota behavior.
